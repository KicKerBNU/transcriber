# Mission

Our mission is to build a real-time conversation transcriber powered by AI.

Users start a session, speak freely, and the app captures every word. As the conversation unfolds, each utterance is streamed to an LLM (OpenAI) which returns intelligent, contextual responses in real time. At the end of the session a full summary of everything discussed is generated automatically — giving users a clear, structured record of the conversation without any manual effort.

## Core Value

> Speak. Understand. Remember.

- **Speak** — capture any conversation through the microphone with a single tap
- **Understand** — get real-time AI responses and insights as the dialogue progresses
- **Remember** — receive an automatic summary so nothing important is ever lost
